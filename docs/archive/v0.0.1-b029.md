Status  : Alpha

## Changes

C : **The last `exit()` calls are out of the library path.**  `arena.c` and `strbuf.c` previously called `exit(1)` on OOM or cap breach — fine for the CLI, fatal for embedders (fuzzer, future LSP).  New `urus_abort` hook (`compiler/include/urus_abort.h` + `src/urus_abort.c`): the embedder arms a `jmp_buf` via `urus_abort_arm`; `urus_abort_oom(msg)` prints and longjmps if armed, `exit(1)`s otherwise.  Five call sites converted: arena chunk OOM, arena per-call cap, `sb_init` OOM, StrBuf 1 GiB cap (both branches), `sb_reserve` realloc-NULL.
C : `urus_compile_buffer` arms the OOM recovery point around the whole pipeline (before any `sb_/arena_` call) and disarms it on every exit path.  An OOM during fuzzing now returns `rc = 1` like any rejected input instead of killing the campaign.
N : `urus_abort_oom` is `noreturn` on both compilers (longjmp transfers control; exit never returns) — keeps the post-`malloc`-NULL paths free of false null-deref warnings.
N : Process-global, single-threaded by design (v0.0.1 has no threads).  Nested compile calls re-arm; the inner disarm does not restore the outer — documented for the v0.0.2 revisit alongside thread-locals.
N : Known leak on the unwind path: a live `StrBuf` at OOM-time is abandoned (its memory is reclaimed by the OS at process end, or accumulates in a long-lived embedder).  Tracked for v0.0.2's allocator-failure-injection rig; under the fuzzer ASan's allocator intercepts long before this fires.
N : With b026 (diag_fatal unwind) + b029, `urus_compile_buffer` is now fully embedder-safe: **no path through the pipeline can terminate the host process.**
