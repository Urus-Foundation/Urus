## Changes

S : **Fuzzing infrastructure** (Tier-1 audit item #17).  New `fuzz/fuzz_compile.c` libFuzzer target drives `urus_compile_buffer` — the same entry point as production — with mutated byte streams.  Any crash / sanitizer report / hang is by definition a compiler bug.  CI gained a `fuzz` job: clang + `-fsanitize=fuzzer,address,undefined`, 5-minute sweep per PR (`-max_total_time=300 -timeout=10 -rss_limit_mb=2048`), crash artifacts uploaded on failure.
A : `compiler/include/compile.h` + `compiler/src/compile.c` — `urus_compile_buffer(src, len, filename, out_c)`: the lex → parse → sema → codegen pipeline as a function over bytes.  Validates UTF-8 up front (same contract as `read_file`), never touches the filesystem, never calls `exit()`.  Returns 0 on success; transfers the emitted-C StrBuf to the caller when requested.
A : `urus_utf8_first_bad_offset` moved from `main.c` (static) to `compile.c` (public) so CLI and fuzz target share one implementation.
A : `scripts/make-corpus.sh` — seeds `fuzz/corpus/` from every `.urus` under `tests/run`, `tests/fail`, and `examples/`.
C : **CMake restructure** — compiler core sources now build as a `urus_core` static library; `urusc` is `main.c` linked against it; the fuzz target links the same library with `-fsanitize=fuzzer-no-link` instrumentation.  Opt-in via `-DURUS_BUILD_FUZZER=ON` (clang required, hard error otherwise).
I : `main.c` keeps its own pipeline driving for the `--tokens` / `--ast` / file-output modes; the shared `urus_compile_buffer` is the *verdict* surface used by fuzzing.  Folding main's emit modes into compile.c is v0.0.2 cleanup.
N : Tier-1 items #16 (sanitizers in CI, b022) and #17 (fuzzing per PR, this build) are both closed.  Next Tier-1 cluster: diagnostics quality (#21 — source-line + caret) lands in b025.
