# v0.0.1-b011

Version : v0.0.1-b011
Date    : 2026-06-04
Status  : Alpha

## Changes

S : `F-COMP-1` *fixed* — parser recursion capped at `URUS_MAX_PARSE_DEPTH` (256) across `parse_type` / `parse_pattern` / `parse_precedence` / `parse_block`; pathological `*****T` no longer blows the host C stack
S : `F-MEM-2` *fixed* — `lex_string` now checks `realloc` result, preserves the old pointer on failure, and emits a fatal diag instead of NULL-deref
S : `F-MEM-5` *fixed* — `read_file` zeroes the tail of the input buffer on short reads, refuses non-regular files via `stat()`, and enforces an upper byte cap
S : Tier-0 #11 — hard cap on input file size: `URUS_MAX_INPUT_BYTES` = 64 MiB; oversize inputs are refused before `fread`
S : Tier-0 #12 — hard cap on a single string literal: `URUS_MAX_STR_LITERAL_BYTES` = 16 MiB; oversize literals emit a fatal diag and stop consuming bytes
S : Tier-0 #13 — `arena_alloc` refuses any single call larger than `URUS_MAX_ARENA_ALLOC` (256 MiB); kills the worst case of F-MEM-3 size-wraparound
S : Tier-0 #14 — `StrBuf` growth path bounded by `URUS_MAX_STRBUF_BYTES` (1 GiB) with explicit overflow-before-add check; closes F-MEM-4 capacity-overflow spin
A : `tests/fail/SEC-02_recursion_bomb.urus` — ~500 leading `*` in a type, must trip the depth cap diagnostic
A : `tests/fail/SEC-03_input_too_large.urus` — documents the manual reproduction for the 64 MiB file cap
A : `tests/run/08_strbuf_growth.urus` — multiple println f-strings to keep StrBuf-growth path covered after the guard rewrite
I : Parser now uses `parse_type_inner` / `parse_pattern_inner` / `parse_precedence_inner` / `parse_block_inner` wrapper pattern so depth bookkeeping is exception-safe (single enter/leave per public call)
N : 4 of 10 stop-ship findings (F-COMP-1, F-MEM-2, F-MEM-5 plus a hardened arena/strbuf) now closed.  Remaining stop-ship: F-MEM-1, F-TY-2, F-COMP-2, F-COMP-3, F-MEM-7, F-MEM-8, F-TY-1.
N : F-MEM-1 (the f-string injection RCE) is still open — `tests/fail/SEC-01_fstr_injection.urus` will continue to "succeed" until a later build re-lexes the placeholder
N : No language-surface changes.  No CHANGELOG `Added`/`Removed`/`Deprecated` entries — this build is pure hardening.
