Version : v0.0.1-b017

Status  : Alpha

## Changes

S : *Runtime hardening — formatter render-size cap.*  `urus_fmt_to_str_n` now refuses results larger than `URUS_FMT_MAX_RENDER_BYTES = 64 MiB` and prints `urus: runtime: format result exceeds URUS_FMT_MAX_RENDER_BYTES` instead of asking `malloc` for a multi-GiB block.  Matches the `URUS_MAX_INPUT_BYTES` shape so a formatter cannot produce more memory pressure than the source it came from.
S : *Runtime hardening — defensive `urus_panic`.*  Caps the printed message at 4 KiB, tolerates a NULL `urus_str.ptr` (default-initialised value), and prints a `(no message)` placeholder rather than feeding `fwrite` a NULL pointer.  A panic payload now cannot itself become a vector.
A : `urus_str_len(s)` — alias for `s.len`, kept as a function so user code reads as `urus_str_len(s)` without poking at the struct.
A : `urus_str_is_empty(s)` — `s.len == 0` as `urus_bool`.
A : `urus_str_eq(a, b)` — length-aware equality, NUL-tolerant, empty == empty.
A : `urus_str_cmp(a, b)` — POSIX-shape `-1 / 0 / +1`, unsigned-byte lex, then length tiebreak.
A : `urus_str_starts_with(s, prefix)` / `urus_str_ends_with(s, suffix)` — empty prefix / suffix always true (mathematically correct; matches Rust / Python).
A : `urus_str_contains(s, needle)` — naive O(n·m) substring; bounded by the 16 MiB lex cap and the new render cap.
A : `URUS_FMT_MAX_RENDER_BYTES = 64 MiB` runtime constant.
A : `tests/run/16_str_helpers.urus` — smokes equality, prefix/suffix, contains, length over a few string pairs.
U : `CHANGELOG.md` `[Unreleased]` section backfilled with b014, b015, b016 entries — pre-b017 it only described b013.  The status footer now reads "All 10 Tier-0 stop-ship findings closed".
N : The new `urus_str_*` helpers are visible from emitted C automatically because they live in `urus_rt.h` (which every TU includes).  Source-level bindings via `use urus.str.*` will land in b019 alongside the explicit stdlib registration.
