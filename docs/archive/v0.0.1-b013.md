## Changes

S : `F-COMP-2` *fixed* — `let mut` enforcement landed in sema.  `Symbol` now carries an `is_mut` flag; `declare_pattern` propagates the binding-site `mut` keyword (let mut, `mut self`, pattern-level `mut x`) into the symbol table.  `EX_ASSIGN` (both `=` and the compound `+= -= *= /= %=` forms) now invokes `check_lhs_mutable`, which classifies the LHS as `PLACE_MUT / PLACE_IMMUT / PLACE_NOT_PLACE / PLACE_UNKNOWN` and reports `cannot assign to immutable binding '<name>'` for the immutable case and `left-hand side of assign to is not assignable` for non-places.  Field/index inherit mutability from their base; deref and qualified paths fall through to the C backend's const-correctness.
S : `F-COMP-3` *fixed* — `match` exhaustiveness check added.  An arm-pass tallies wildcard / bare-ident catch-alls and collects unguarded enum-variant arm names; absent a catch-all, sema checks the variant set against (a) the builtin pair `{Ok, Err}` for Result, (b) `{Some, None}` for Option, and (c) any user-defined enum whose variant set the seen names belong to.  Missing variants emit `non-exhaustive match on '<TypeName>': missing variant '<Variant>' (or add a '_' wildcard)`.  Guarded arms do not count toward coverage — a `match x { Ok(v) if v > 0 => ..., Err(e) => ... }` is still non-exhaustive because the guard can fail.
A : `tests/fail/SEC-04_assign_immut.urus` — `let x = 1; x = 2;` must be rejected.
A : `tests/fail/SEC-05_assign_immut_compound.urus` — `let n = 10; n += 5;` must be rejected.
A : `tests/fail/SEC-06_match_nonexhaustive_result.urus` — Result match without `Err` arm rejected.
A : `tests/fail/SEC-07_match_nonexhaustive_option.urus` — Option match without `None` arm rejected.
A : `tests/run/11_let_mut.urus` — `let mut x = 0; x = 1; x += 41;` must compile cleanly.
A : `tests/run/12_match_wildcard.urus` — wildcard arm satisfies exhaustiveness even when Err is implicit.
I : `Symbol.is_mut` field added; preserved through `scope_grow` because the rehash copies the whole struct.
I : `declare_pattern` signature gained `bool outer_mut` parameter; all 7 call sites updated (let, match, for, fn params, recursive tuple/variant).
I : `classify_lhs` / `describe_lhs` / `check_lhs_mutable` helpers live in `compiler/src/sema.c` next to the place-mutability enum `PlaceMut`.
N : 9 of 10 stop-ship findings now closed: F-COMP-1, F-MEM-2, F-MEM-5 in b011; F-MEM-7, F-MEM-8, F-TY-1 in b012; F-COMP-2 and F-COMP-3 in b013.  Remaining stop-ship: F-MEM-1 (f-string codegen RCE) and F-TY-2 (Result/Option payload truncation).
N : Mutability through pointers / references is intentionally accepted by the new sema — v0.0.1 has no type-flow that recovers a pointer's `*mut` tag from an `Expr`.  The C backend's const correctness is the line of defence there until v0.0.2 brings a typed IR.
