# v0.0.1-b021

Version : v0.0.1-b021
Date    : 2026-06-04
Status  : Alpha

## Changes

S : *`&mut` borrow gate* — `&mut x` over an immutable binding is now rejected with the same `check_lhs_mutable` machinery that gates direct assignment (F-COMP-2, b013).  This closes the loophole where code could take a mutable borrow of an immutable binding and write through the pointer, bypassing the b013 check entirely.  A plain `&x` places no obligation.
A : *Duplicate parameter detection* — `fn add(x: i32, x: i32)` is rejected at sema with `duplicate parameter 'x' in function 'add'`.  Pre-b021 the second `x` silently shadowed the first (scope_define returns the existing slot on name match) and the failure surfaced only as a confusing host-C error.
A : *Stray `self` detection* — a free function taking `self` errors with `function '<name>' takes \`self\` but is not inside an \`impl\` block`; `self` in non-first position errors with `\`self\` must be the first parameter`.
A : *Unused-`mut` warning* — at end of every block and fn scope, bindings declared `mut` but never assigned nor `&mut`-borrowed warn: `binding '<name>' is declared \`mut\` but never mutated — consider dropping \`mut\``.  Warning, not error — compilation proceeds.  `self` receivers are exempt (methods commonly mutate through fields invisible to this pass).
A : `tests/fail/SEC-14_dup_param.urus`, `SEC-15_self_outside_impl.urus`, `SEC-16_ref_mut_immutable.urus`.
A : `tests/run/19_unused_mut_warns.urus` — exercised/unused/borrowed `mut` trio; must exit 0 while emitting exactly one warning.
I : `Symbol` gained `written` (assignment or `&mut` borrow seen) and `loc` (binding site, for end-of-scope diagnostics).  `classify_lhs` sets `written = true` on the PLACE_MUT path.  New `warn_unused_mut(s, scope)` sweeps a scope's slots before it dies; called from `check_block` and `check_fn`.
N : The warning channel (`diag_warn`) existed in `diag.h` since b001 but had zero call sites until this build.  Sema now distinguishes hard rule violations from style-grade advice.
