## Changes

A : **GitHub Actions CI** (`.github/workflows/ci.yml`) — first automated pipeline for the project.  Two jobs:
    - `build-test` matrix: gcc + clang on `ubuntu-latest`, clang on `macos-latest`, MSVC-cmake on `windows-latest`.  (The *compiler* builds fine under MSVC; only the *emitted C* requires GCC/Clang statement expressions, and the harness validates via `--emit-c` so no host C compile is needed.)  Each leg builds via CMake and runs the b020 harness (`run-tests.sh` / `run-tests.ps1`).
    - `sanitize`: clang with `-fsanitize=address,undefined -fno-sanitize-recover=all` over the full test sweep.  `detect_leaks=0` by policy — urusc is a short-lived process that exits without freeing arena-backed structures; leak noise would drown real ASan signal (UAF, OOB, double-free all still fatal).
S : This lands Tier-1 audit item *"ASan+UBSan in CI"* (item #16 in the TOP-100 list).  libFuzzer 5min/PR (item #17) remains open — needs a fuzz target entry point split out of `main.c` first.
N : `permissions: contents: read` — workflow runs with a read-only token; no write scopes.
N : `fail-fast: false` on the matrix so a Windows failure doesn't mask a Linux sanitizer report in the same run.
