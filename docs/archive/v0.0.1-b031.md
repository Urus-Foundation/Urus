# v0.0.1-b031 — 2026-06-07

> **Status:** Alpha
> **Theme:** First CI run green + first fuzzer findings fixed. The
> v0.0.1 merge was the first time the b022 CI matrix actually executed;
> this build clears every environment failure it surfaced, then fixes
> the two real memory-safety bugs the first genuine fuzz runs caught.

## Changes

- `S` `compiler/src/lexer.c` — **fuzzer finding #1**: a lone `'` at end
  of input made `lex_char` advance past the NUL terminator and read out
  of bounds (ASan heap-buffer-overflow in `peek0`).  EOF guards added
  before the char consume and after the backslash; same latent pattern
  fixed in `lex_string`'s escape path (trailing `\` consumed the NUL
  and kept scanning).  Regressions:
  `tests/fail/SEC-18_char_eof.urus`,
  `tests/fail/SEC-19_str_escape_eof.urus`.
- `S` `compiler/src/arena.c` — **fuzzer finding #2** (OOM): new
  `URUS_MAX_ARENA_TOTAL` (512 MiB) bounds the *sum* of arena
  allocations; the existing 256 MiB cap only bounded one call, so many
  small AST allocations could still OOM the process.  Unwinds through
  `urus_abort_oom` like the per-call cap.
- `S` `compiler/src/parser.c` — **fuzzer finding #3** (LeakSanitizer):
  the parser's grow-buffer scratch (`realloc` + `free` after the arena
  copy) leaked on every early-`return`/`break` path out of a collection
  loop, and would also leak under the b026/b029 longjmp unwind (the
  `free` never runs).  All 19 scratch buffers converted to arena-backed
  `arena_grow` — the arena teardown (normal or unwind) now frees the
  scratch with everything else, removing the entire leak class instead
  of patching paths one by one.
- `S` `compiler/include/urus_common.h` + 21 call sites — `urus_memcpy`
  NULL-tolerant wrapper: the parser's grow-buffer pattern passes
  `src=NULL, n=0`, which UBSan flags as UB via memcpy's nonnull
  attribute.
- `F` `scripts/run-tests.sh` / `scripts/make-corpus.sh` — executable
  bit set (committed from Windows; POSIX CI jobs died with
  `Permission denied`).
- `F` `scripts/run-tests.ps1` — explicit `exit 0`: the final self-test
  intentionally exits non-zero and GitHub's pwsh wrapper propagates
  `$LASTEXITCODE`, failing the job after "43 passed, 0 failed".
- `F` `compiler/CMakeLists.txt` — under `URUS_BUILD_FUZZER=ON`, `urusc`
  links the sanitizer-instrumented `urus_core`, so it needs
  `-fsanitize` link flags too (undefined `__asan_*` / `__sancov_*`
  references).
- `U` `fuzz/fuzz_compile.c` — input cap 1 MiB → 64 KiB: every
  resource-cap path triggers far below it, and codegen output is
  super-linear in input size, so larger inputs only bought RSS spikes.
- `T` Suite grows to **45 passed** (SEC-18, SEC-19 added).
