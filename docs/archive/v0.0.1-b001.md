Version : v0.0.1-b001

## Changes

A : First C-based `urusc` compiler binary scaffold (~3 500 LOC)
A : Lexer with full token set, escape sequences, numeric prefixes, nested block comments
A : Recursive-descent + Pratt expression parser, 18 precedence levels
A : Discriminated-union AST with arena-backed lifetimes
A : Two-pass semantic analyzer (collect globals → check bodies)
A : C99 transpile backend emitting one self-contained translation unit
A : Header-only runtime `stdlib/runtime/urus_rt.h` — `urus_str`, `Result`, `Option`, `println`, `panic`
A : CLI surface `--emit-c`, `--emit-tokens`, `--emit-ast`, `-o`, `--version`, `--help`
A : Examples — hello, aurochs, fib, result
A : Tests — `tests/run/{01..04}.urus`, `tests/fail/{01,02}.urus`
A : Test runners — `scripts/run-tests.ps1`, `scripts/run-tests.sh`
A : Top-level docs — README, ROADMAP, CHANGELOG, CONTRIBUTING, GOVERNANCE, SECURITY, LICENSE
L : English keywords baseline (`fn struct impl enum match Result Option …`) — overrides earlier Indonesian-keyword sketch
N : Pre-alpha. Not safe for untrusted input. Compiler not yet smoke-tested (no host C compiler installed).
