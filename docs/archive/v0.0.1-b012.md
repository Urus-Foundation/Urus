# v0.0.1-b012

Version : v0.0.1-b012
Date    : 2026-06-04
Status  : Alpha

## Changes

S : `F-MEM-7` *fixed* — codegen now emits an explicit element count alongside the `urus_fmt_arg[]` initialiser and calls `urus_*_fmt_n(args, count)`.  The sentinel-terminated wrappers still exist for back-compat but bound their scan at `URUS_FMT_MAX_ARGS` (1024), so a missing-`END` cannot walk the heap.
S : `F-MEM-8` *fixed* — `URUS_FMT_PTR_TAG` removed from the runtime entirely.  `URUS_FMT_ANY` routes `char *` / `const char *` through `urus__fmt_from_cstr`, which wraps the pointer in a length-bounded `urus_str` via `strlen` at the call site.  No more "treat arbitrary pointer as null-terminated C string" primitive in the renderer.
S : `F-TY-1` *fixed* — `urus_opt_tag` reassigned to disjoint values (`URUS_OPT_NONE = 2`, `URUS_OPT_SOME = 3`).  A cross-cast (treating an `Option` as a `Result` or vice versa) now always fails the `urus_is_*` check instead of aliasing.
A : `urus_println_fmt_n` / `urus_print_fmt_n` / `urus_eprintln_fmt_n` / `urus_fmt_to_str_n` — length-aware public API.
A : `urus__fmt_from_cstr` — internal helper wrapping `const char *` into a `urus_str` for the `_Generic` dispatch.
A : `URUS_FMT_MAX_ARGS` (1024) — hard cap on the back-compat sentinel scan.
R : `URUS_FMT_PTR_TAG` removed from `urus_fmt_tag` enum and from the `urus_fmt_arg` union (the `.p` member is gone).
B : Source that explicitly named `URUS_FMT_PTR_TAG` will fail to compile.  No such source exists in the URUS codebase; downstream users on v0.0.1-b011 or earlier need to rebuild.
A : `tests/run/09_disjoint_tags.urus` — verifies Result/Option no longer alias.
A : `tests/run/10_println_length.urus` — exercises the `_fmt_n` length-aware path + `char *` dispatch through the new helper.
I : `cg_fmt_arg_array` now returns the emitted element count (`uint32_t`), still followed by a trailing `URUS_FMT_END` so the back-compat runtime path continues to work.
N : 7 of 10 stop-ship findings now closed: F-COMP-1, F-MEM-2, F-MEM-5 in b011; F-MEM-7, F-MEM-8, F-TY-1 in b012.  Remaining: F-MEM-1 (f-string codegen RCE), F-TY-2 (Result/Option payload truncation), F-COMP-2 (`let mut` enforcement), F-COMP-3 (`match` exhaustiveness).
